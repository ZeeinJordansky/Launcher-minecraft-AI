# Состояние проекта

## Исходники v0.5.0

- Собственная безрамочная панель заголовка с акцентными кнопками свернуть, развернуть и закрыть; двойной клик по панели меняет состояние окна.
- Обновлённая фирменная иконка Minty Launcher, синхронизированная с иконкой установщика.
- Java Runtime обнаруживается и проверяется без видимых окон командной строки. Minecraft запускается через javaw.exe.
- Каталог Modrinth использует одинаковые карточки, фиксированные размеры кнопок и двухколоночную сетку.
- Верхний профиль объединяет аватар, имя и статус; нажатие на аватар открывает профиль и редактор скинов.
- Skin Workshop: UV-атлас 64×64, кисть, ластик, заливка, пипетка, прозрачность, размер, зеркальное рисование,
  отражение текстуры, сетка, внешний слой, предпросмотр, undo/redo, PNG импорт/экспорт и локальное сохранение.
- Настройки: 10 языков для навигации и основных разделов, проверка обновлений при старте, закрытие после запуска игры,
  дополнительные пояснения к Java, графике и оформлению.
- Список настроек прокручивается независимо от содержимого; подписи и статус адаптируются к доступной ширине.

## Публикация

Windows x64 CI выполняет cargo test, release build, проверку PE и сборку установщика.
Release v0.5.0 должен быть опубликован только после успешного Windows Actions workflow и наличия EXE и Setup в релизе.

## Оставшиеся ограничения

- Переводы v0.5.0 покрывают навигацию и ключевые названия разделов; часть подробных описаний настроек остаётся на русском.
- Установка модпаков, ресурспаков и шейдеров пока открывает страницу проекта; установка бинарного JAR поддерживается только для модов.
- Прямая установка CurseForge через API требует API-ключа.
- Ely.by/Mojang skin upload и плащи ещё не подключены; локальное редактирование и экспорт PNG работают.
- Skin preview остаётся 2D-композицией, а не полнофункциональной вращаемой 3D-моделью.
- Windows sandbox/AppContainer не реализован.
- Статическая проверка модов не является антивирусом и не разрешает все зависимости.
- Bedrock version pinning и rollback контролирует Microsoft Store.
- EXE не подписан Authenticode.
