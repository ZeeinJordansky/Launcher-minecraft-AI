# Состояние проекта

## Реализовано в исходниках v0.4.0

- Русский интерфейс, верхняя навигация, переходы, аватар справа, центрированный статус.
- Splash: проверка обновлений → поиск установленной Java → загрузка основного интерфейса.
- Главная библиотека сканирует локальные профили и показывает только найденные установленные сборки.
- Java Edition: существующая установка и запуск версий, обнаружение/установка Temurin.
- Опциональная изоляция изменяемых папок профилей.
- Каталог Modrinth, поиск и установка JAR.
- Статическая проверка JAR на повреждение, повторяющиеся mod ID и метаданные загрузчика.
- Настройка G1GC/ZGC/Shenandoah и полноэкранного запуска.
- Skin Studio, Microsoft OAuth, «Слабый ПК», журнал и аппаратная оценка.
- Crash Reporter для ряда типовых ошибок.
- Bedrock Stable/Preview: запуск существующей установки и импорт пакетов.
- Цветовые пресеты и updater.

## Публикация

Windows x64 CI выполняет cargo test, release build, проверку PE и сборку установщика. GitHub Release v0.4.0 считается опубликованным только после успешного Actions workflow и наличия EXE и Setup в релизе.

## Оставшиеся ограничения

- Прямая установка CurseForge через API требует API-ключа.
- Bedrock version pinning/rollback контролирует Microsoft Store; реализован выбор Stable/Preview.
- Static mod scan не разрешает все зависимости и не выявляет произвольный вредоносный код.
- Windows sandbox/AppContainer ещё не реализован.
- Точный FPS benchmark не реализован; показываем аппаратную оценку без фиктивного FPS.
- Ely.by/Mojang skin upload и плащи ещё не подключены; сейчас работает локальный редактор.
- Authenticode signing отсутствует.


## Дополнения редактора и настроек
- Skin Workshop: UV-атлас с выбором областей, кисть/ластик/заливка/пипетка, масштаб, размер кисти, зеркальное рисование, палитра, предпросмотр, история отмены и повторения, PNG импорт/экспорт.
- Настройки разделены на основные, Minecraft, Java, производительность, оформление, аккаунт, файлы и хранилище, безопасность, обновления и журнал.
- Modrinth каталог поддерживает типы проектов и сортировку. Файлы JAR устанавливаются только в категорию модов; остальные проекты открываются на странице Modrinth.
