# Настройка входа через Microsoft

Minty Launcher использует Microsoft OAuth 2.0 Device Code Flow с публичным Client ID. Пользователю не нужно регистрировать приложение или вводить Client Secret.

1. Открой раздел «Аккаунты» и нажми «Войти в Microsoft».
2. Подтверди одноразовый код на официальной странице Microsoft.
3. Лаунчер проверит цепочку Microsoft → Xbox Live → XSTS → Minecraft Services, entitlement Minecraft: Java Edition и профиль.

Refresh token сохраняется в Windows Credential Manager. Access token используется только в памяти для запуска игры и не сохраняется в `settings.json`. Вход поддерживается Windows-сборкой, поскольку для безопасного хранения токена требуется системное хранилище учётных данных.

## Офлайн-профиль

Офлайн-профиль запускается без Microsoft-сессии и предназначен для одиночной игры/локальных сценариев. Он не подтверждает владение Minecraft; онлайн-серверы могут требовать официальную авторизацию.
