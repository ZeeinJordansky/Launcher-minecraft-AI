# Решение проблем

## Не загружается список версий

Проверь доступ к `piston-meta.mojang.com` и серверам Mojang. Состояние и причины ошибок смотри в разделе «Журнал».

## Ошибка Microsoft OAuth

Проверь OAuth Client ID, тип приложения, Device Code Flow и Xbox-разрешения. Для авторизации нужен Microsoft-аккаунт с лицензией Minecraft Java Edition.

## Minecraft закрывается сразу

Открой «Журнал» и проверь последнюю ошибку. Убедись, что на диске достаточно места и антивирус не заблокировал Java Runtime или native-библиотеки. При необходимости удали только папку проблемной версии или её natives — не удаляй весь каталог игры, если в нём есть миры.

## Java Runtime не скачивается

Minty загружает Temurin JRE через API Adoptium. Проверь доступ к `api.adoptium.net` и CDN загрузки. При установленной совместимой Java можно указать путь к `javaw.exe` в настройках.

## Скин не отображается в офлайн-игре

Skin Studio создаёт обычный PNG-файл. Чистый Vanilla Minecraft не загружает локальную текстуру в офлайн-профиль; для использования в игре нужен совместимый мод загрузки локальных скинов.

## Windows SmartScreen

Исполняемый файл пока не подписан сертификатом Authenticode. Скачивай `.exe` только из GitHub Releases официального репозитория.
