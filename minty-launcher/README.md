# Minty Launcher

**Minty Launcher** — нативный лаунчер Minecraft Java Edition для Windows 10/11 x64. Интерфейс и управление загрузкой реализованы на Rust (`egui`), а запуск целевой JVM выполняет небольшой Java bootstrap.

## Возможности

- **Установка Vanilla Minecraft:** загрузка официального манифеста Mojang, выбор релиза, client JAR, библиотек, native-библиотек и игровых ресурсов.
- **Проверка файлов:** SHA-1 сверяется с контрольными суммами, опубликованными Mojang; повреждённые загрузки скачиваются заново.
- **Java Runtime:** поиск подходящей Java и автоматическая установка Temurin JRE нужной версии при необходимости.
- **Microsoft-вход:** Device Code Flow, обмен через Xbox Live/XSTS и проверка профиля и лицензии Minecraft Java Edition.
- **Офлайн-профиль:** запуск одиночной игры с локальным ником; он не выдаёт лицензию и не позволяет авторизоваться на серверах, требующих Microsoft-аккаунт.
- **Skin Studio:** локальный редактор PNG-текстуры 64×64 (поддерживается импорт старого формата 64×32), рисование пикселями, импорт и экспорт. Для автоматического отображения кастомного скина в офлайн-игре чистому Vanilla нужен отдельный мод загрузки скинов.
- **Режим «Слабый ПК»:** профиль графики с меньшей дальностью прорисовки, меньшим количеством эффектов, ограничением Java-памяти до 2 GB и более щадящими JVM-параметрами. Исходный `options.txt` резервируется и восстанавливается при отключении режима. Повышение FPS зависит от конкретного компьютера и не гарантируется.
- **Каталог установки:** выбор любой доступной папки для `.minecraft`, включая библиотеки, версии и ресурсы.
- **Журнал:** локальные записи об авторизации, загрузках, настройках и запуске игры.
- **Настройки:** Java executable, объём памяти, OAuth Client ID, каталог игры и профиль производительности.
- **Современный интерфейс:** тёмная тема с мятными акцентами, главная страница, установки, редактор скина, журнал и настройки.

## Первый запуск

1. Открой GitHub Releases и скачай `MintyLauncher.exe`.
2. Запусти лаунчер. При первой установке выбери папку Minecraft в настройках или оставь стандартную `.minecraft`.
3. Выбери официальную версию Minecraft Java Edition.
4. Для одиночной игры введи локальный ник. Для лицензионных серверов настрой Microsoft OAuth Client ID и выполни вход.
5. Нажми «Запустить Minecraft». При первом запуске будут скачаны игровые файлы и подходящая Java Runtime.

## Сборка из исходников

Нужны Windows 10/11 x64, Rust stable с MSVC toolchain, Visual Studio Build Tools с C++ workload и JDK 21 (`javac` в `PATH`). Подробная инструкция находится в [docs/BUILDING.md](docs/BUILDING.md).

```cmd
cargo build --release --target x86_64-pc-windows-msvc
```

## Ограничения текущей версии

- Поддерживаются официальные Vanilla release. Fabric, Forge, NeoForge и импорт модпаков пока не реализованы.
- Skin Studio сохраняет и редактирует PNG-текстуру локально. Vanilla не загружает этот локальный файл в офлайн-профиль сам по себе; нужен совместимый мод с поддержкой локальных скинов.
- Режим «Слабый ПК» применяет более лёгкие игровые настройки и JVM-ограничения. Реальный прирост FPS зависит от железа, версии игры, драйверов и модификаций.
- Проверка контрольных сумм не является античитом и не гарантирует обнаружение стороннего ПО или изменённых клиентов.
- Официальная авторизация требует собственного публичного Microsoft OAuth Client ID. Client Secret хранить в клиентском приложении нельзя.
- Исполняемый файл не подписан сертификатом Authenticode, поэтому Windows SmartScreen может показать предупреждение об издателе.
