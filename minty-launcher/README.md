# Minty Launcher

**Minty Launcher** — нативный лаунчер Minecraft Java Edition для Windows 10/11 x64. Интерфейс и управление загрузкой реализованы на Rust (egui), а запуск целевой JVM выполняет небольшой Java bootstrap.

## Иконка приложения

![Minty Launcher](assets/minty-launcher-icon.png)

Иконка включена в minty-launcher.exe: она используется и в окне, и в PE-ресурсах Windows. Отдельный ICO рядом с EXE не требуется.

## Возможности

- Установка Vanilla Minecraft: официальный манифест Mojang, выбор релиза, client JAR, библиотеки, native-библиотеки и ресурсы.
- Проверка SHA-1 по опубликованным Mojang контрольным суммам.
- Автоматическая установка Temurin JRE подходящей версии.
- Microsoft Device Code Flow, обмен через Xbox Live/XSTS и проверка профиля и лицензии Minecraft Java Edition.
- Офлайн-профиль для одиночной игры.
- Skin Studio: локальный редактор PNG-текстуры 64×64 (импорт старого формата 64×32), рисование пикселями, импорт и экспорт.
- Режим Слабый ПК: меньшая дальность прорисовки, меньше эффектов, лимит Java-памяти до 2 GB и более щадящие JVM-параметры. Исходный options.txt резервируется и восстанавливается при отключении режима. Прирост FPS зависит от компьютера и не гарантируется.
- Выбор любой доступной папки .minecraft.
- Локальный журнал авторизации, загрузок, настроек и запуска игры.
- Настройки Java executable, объёма памяти, OAuth Client ID, каталога игры и профиля производительности.
- Тёмная тема с мятными акцентами и фирменная иконка приложения.

## Ограничения

- Поддерживаются официальные Vanilla release. Fabric, Forge, NeoForge и импорт модпаков пока не реализованы.
- Skin Studio сохраняет локальную PNG-текстуру. Vanilla не загружает этот локальный файл в офлайн-профиль сам по себе; нужен совместимый мод.
- Слабый ПК применяет более лёгкие игровые настройки и JVM-ограничения. Реальный прирост FPS зависит от железа, драйверов и мира.
- Проверка контрольных сумм не является античитом.
- Официальная авторизация требует собственного публичного Microsoft OAuth Client ID.
- Исполняемый файл не подписан сертификатом Authenticode, поэтому Windows SmartScreen может показать предупреждение об издателе.
