# Security policy

Report security issues privately to the repository maintainers rather than publishing tokens, personal data, or exploit details in public issues.

Minty Launcher verifies official downloads against Mojang-published hashes when available and stores Microsoft refresh tokens in the operating system credential store. The launcher is not an anti-cheat and cannot guarantee detection of modified clients or malicious local software. Never send Microsoft tokens, Client Secrets, or credential-store exports in bug reports.
